# Installation

This fork publishes no binaries. Build confd from a release tag with Go 1.26 or later:

```
go install github.com/wodby/confd@latest
```

Or build from a checkout:

```
git clone https://github.com/wodby/confd.git
cd confd
make build
```

The binary is written to `bin/confd`.
